# jerusalem-projects-dashboard
דשבורד בקרת לוחות זמנים - פרויקטי בינוי מוסדות חינוך ירושלים

## משחקים

שני קבצי HTML עצמאיים, כל אחד עומד בפני עצמו (גופנים מוטמעים בפנים, בלי תלות חיצונית),
עובדים בפלאפון גם בלי אינטרנט. הדשבורד ב-`index.html` לא מושפע מהם.

- **`dinner-wheel.html`** — גלגל שמגריל מה אוכלים לארוחת ערב. מוסיפים שמות של מאכלים, מסובבים, והגלגל בוחר. הרשימה נשמרת במכשיר.
- **`date-cards-wheel.html`** — גלגל כרטיסיות לדייט: 51 שאלות בשש ערימות. הגלגל בוחר ערימה ושולף ממנה שאלה שעוד לא עלתה, עם מעקב תור בין שני שחקנים. ההתקדמות נשמרת במכשיר.
